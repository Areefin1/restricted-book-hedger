## Accounting and data requirements

These equations identify the conventions the team needs to settle; they are not instructions to replace the observed SJB series with a theoretical return.

Let `A = H(T)/H(0)`, `G` be gross growth of the cash account over exactly the same period, and `V` integrated variance. Paper equations (4) and (6), PDF p.8, give the following gross returns for a separately capitalized fund with leverage multiple `p`:

`continuous gross = G^(1-p) * A^p * exp[-0.5*p*(p-1)*V]`

`no-rebalance gross = p*A + (1-p)*G`

For `p=-1`, the no-rebalance **fund** gross return is `2*G-A`; both its initial capital and short-sale proceeds earn cash returns. Its excess return is exactly minus the index excess return. In contrast, a short **overlay** on an existing book has no separate initial investor capital in the hedge, so its short-sale-proceeds contribution can legitimately be only one `G-1` term. Do not mechanically double that term in this repo. An inverse-fund overlay purchased with borrowed money must also account for repayment and interest on that external borrowing. At matched risk-free funding and ideal tracking, subtracting that funding reconciles the standalone fund with the overlay.

The code currently computes `G` by multiplying `1 + rf_interval`, where `rf_interval = (1 + annual_pct/100)^(calendar_days/365)-1` using the prior observed quote. This is arithmetically consistent **if** those quotes are effective annual rates applicable to that interval. The current provenance does not establish that premise. Daily RF returns from a source such as the paper's Ken French series must instead be converted from the source's actual units and aligned to its defined return intervals.

For daily research, use `asset_excess[t] = asset_total_return[t] - cash_return[t]`. For a window, use `asset_total_window_return - cash_total_window_return`, with each total compounded separately. The current endpoint adjusted-price ratio is a valid total-return calculation under the vendor's adjustment convention. A simple `-HYG_total_return` hedge reference is a deliberately zero-carry return-series P/L reference and should be labeled that way.

For N research returns, a zero-mean measure consistent with the substance of equation (20) is `sqrt(sum(excess_return[t]^2))`; an explicitly annualized version is `sqrt((252/N)*sum(excess_return[t]^2))`. For fixed N, annualization changes scale but not tercile ranks. Demeaning changes ranks. Sample standard deviation around the estimated mean remains a reasonable separately labeled descriptive portfolio-risk statistic; it should not be silently substituted for the paper's research measure. Resolve the equation's written bounds as noted in F26.

At zero interest, an ideal daily multiple uses `product(1+p*r[t])-1`, while the static reference uses `p*(product(1+r[t])-1)`. Table 1's four outcomes should be regression checks for both +/-3 multiples; a -1 adaptation is also valid when clearly labeled. A continuously rebalanced diffusion is not the same as a daily fund facing jumps or implementation costs. Any theoretical extension must handle `1+p*r<=0`, financing constraints, interruptions and liquidation explicitly; the paper's strictly positive diffusion result assumes continuous prices (PDF p.9).
